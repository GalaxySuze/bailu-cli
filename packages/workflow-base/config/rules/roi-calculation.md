# ROI 计算规则

## ROI 定义

```
ROI = (收益 - 成本) / 成本 × 100%
```

## 收益计算

### 时间节省
- **手动编码时间**: 假设手动完成任务需要的时间
- **AI 辅助时间**: 使用 AI 完成任务的实际时间
- **时间节省**: 手动时间 - AI 时间

### 价值计算
- **时薪设置**: $50/小时（可根据实际情况调整，请在 WebUI 的 ROI 配置页面中修改）
- **时间价值**: 时间节省 × 时薪

## 成本计算

### 直接成本
- Token 使用成本
- API 调用成本

### 间接成本
- 学习成本（首次使用）
- 配置成本（初始设置）

## 追踪指标

### 效率指标
- **任务完成数**: 每日/每周/每月完成的任务数
- **平均任务时间**: 完成单个任务的平均时间
- **代码行数**: 生成的代码行数
- **测试覆盖率**: AI 生成的测试覆盖率

### 质量指标
- **代码质量评分**: 静态分析得分
- **Bug 率**: AI 生成代码的 Bug 率
- **审查通过率**: 代码审查一次通过率

## ROI 计算示例

### 示例 1：代码生成
```
手动时间: 4 小时
AI 时间: 1 小时
时间节省: 3 小时
时薪: $50
时间价值: $150

Token 成本: $5.00
ROI = ($150 - $5) / $5 × 100% = 2,900%
```

### 示例 2：代码审查
```
手动时间: 2 小时
AI 时间: 0.5 小时
时间节省: 1.5 小时
时薪: $50
时间价值: $75

Token 成本: $2.00
ROI = ($75 - $2) / $2 × 100% = 3,650%
```

## 报表展示

### 仪表盘指标
- **总 ROI**: 所有任务的综合 ROI
- **平均 ROI**: 每个任务的平均 ROI
- **时间节省总计**: 累计节省的时间
- **价值创造总计**: 累计创造的价值
