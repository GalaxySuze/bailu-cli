# 监控规则

## Token 使用监控

### 预警阈值
- **警告阈值**: 100,000 tokens/天
- **严重阈值**: 200,000 tokens/天

### 监控指标
- 每日 Token 使用量
- 每会话 Token 使用量
- 每工作流 Token 使用量
- Token 使用趋势

### 告警规则
1. 当 Token 使用量超过警告阈值时，发送桌面通知
2. 当 Token 使用量超过严重阈值时，发送桌面通知 + Bridge 通知
3. 每日结束时生成 Token 使用报告

## 成本监控

### 预算设置
- **日预算**: $50.00
- **月预算**: $1,000.00

### 成本计算
- 根据模型定价计算实时成本
- 区分输入成本和输出成本
- 按模型、会话、工作流分类统计

### 告警规则
1. 当日成本达到预算 80% 时，发送警告
2. 当日成本超出预算时，发送严重告警
3. 当月成本达到预算 90% 时，发送警告
4. 当月成本超出预算时，发送严重告警

## 性能监控

### 响应时间
- 监控每次 API 调用的响应时间
- 记录 P50、P95、P99 响应时间
- 响应时间超过阈值时告警

### 成功率
- 监控 API 调用成功率
- 失败率超过阈值时告警
- 记录失败原因分类

## 数据保留

- Token 使用数据：保留 90 天
- 成本数据：保留 1 年
- 告警记录：保留 180 天
- 性能数据：保留 30 天
