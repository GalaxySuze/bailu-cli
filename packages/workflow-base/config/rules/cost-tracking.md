## 成本分类

### 按用途分类
- **开发成本**: 代码生成、调试、重构
- **审查成本**: 代码审查、安全审计
- **文档成本**: 文档生成、翻译
- **学习成本**: 问题解答、知识查询

### 按工作流分类
- **dev 工作流**: 开发相关成本
- **ops 工作流**: 运营相关成本
- **base 配置**: 基础配置成本

## 成本优化建议

### Token 优化
1. 使用更简洁的提示词
2. 避免重复的上下文
3. 使用缓存减少重复请求
4. 选择合适的模型（简单任务用 Haiku）

### 预算管理
1. 设置合理的日预算和月预算
2. 监控预算使用情况
3. 及时调整预算策略
4. 分析成本构成，找出优化点

## 报表生成

- 本周 Token 使用趋势

### 月报
