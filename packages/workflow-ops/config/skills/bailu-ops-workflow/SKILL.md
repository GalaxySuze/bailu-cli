# 白鹿运营工作流

当用户提到运营相关关键词时，自动进入此工作流。

## 品牌信息

- **名称**：白鹿（Bailu）
- **前缀**：bailu:
- **Agent**：bailu:ops-workflow
- **寓意**：林深见鹿——在复杂的代码森林中，发现优雅的解决方案

## 工作流阶段

### 阶段1：主题探索与澄清
**目标**：确定内容主题、目标受众、核心价值

**推荐工具**：
- `brainstorming`：头脑风暴选题
- `market-research`：市场调研

**人工节点**：
- 主题确认

### 阶段2：形式判定
**目标**：根据内容特点选择图文还是视频

**决策树**：
- 信息密度高、需要快速浏览 → 图文
- 需要故事性、情感共鸣 → 视频

**视频子类型**：
- 口播知识分享 → HTML PPT + 口播脚本
- 故事性内容 → 动画视频 + 分镜脚本

**人工节点**：
- 形式确认

### 阶段3：内容创作
**目标**：根据形式创建内容

**图文工具**：
- `frontend-design`：HTML原型（文章转图片）
- `banner-design`：横幅设计
- `design`：综合设计
- `slides`：演示文稿

**视频工具（HTML PPT）**：
- `frontend-slides`：HTML演示文稿
- `guizang-ppt-skill`：横向翻页PPT

**视频工具（动画故事）**：
- `article-writing`：脚本撰写
- `content-engine`：内容策略

**人工节点**：
- 内容确认

### 阶段4：发布准备
**目标**：检查内容质量，准备发布

**检查清单**：
- 标题是否吸引人
- 封面图是否清晰
- 内容是否符合平台规范
- 标签是否合适

**人工节点**：
- 最终确认（必须人工发布，不自动发布）

## 平台规范

### 小红书
- 封面尺寸：1080x1440
- 标题长度：≤20字
- 内容长度：≤1000字
- 图片格式：jpg/png

### 抖音
- 视频比例：9:16
- 时长：15-60秒

### 公众号
- 封面尺寸：900x383
- 内容宽度：1080px

## 决策原则

1. **Agent思维**：根据内容特点自主选择工具和形式
2. **人工确认**：所有内容必须经过人工确认才能发布
3. **不自动发布**：发布操作必须人工执行
