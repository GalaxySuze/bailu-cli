# 白鹿 SDD 启动

## 概述

启动白鹿 SDD（Specification-Driven Development）研发流程。

## 使用方法

在 Claude Code 中运行：

```
/bailu-sdd-start
```

或者直接告诉 Claude：

```
启动白鹿研发流程
```

## 流程说明

SDD 流程包含 7 个阶段：

1. **D1 - 需求规划**：理解需求，制定计划
2. **D2 - 技术设计**：架构设计，接口定义
3. **D3 - 代码实现**：编码实现，单元测试
4. **D4 - 测试验证**：集成测试，性能测试
5. **D5 - 代码审查**：代码审查，安全检查
6. **D6 - 部署上线**：部署准备，上线发布
7. **D7 - 迭代优化**：反馈收集，持续改进

## 快捷入口

- `/bailu-hotfix` - 快速修复（跳过规划阶段）
- `/bailu-tweak` - 小改动（跳过规划和设计）

## 注意事项

- 每个阶段都有明确的产出物和验收标准
- 支持随时暂停和恢复
- 所有决策都有记录，便于追溯
