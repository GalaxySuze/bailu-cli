# Story Points 字典

用于 D1 任务拆解后的工作量估算。优先匹配具体技术方向；无法判断时使用通用参考基准。跨模块任务分别估算后汇总。

> SP 字典为参考基准，非强制标准。团队可根据自身情况自定义扩展。
