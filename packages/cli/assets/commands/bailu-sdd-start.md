# 白鹿 SDD 研发流程

## 品牌信息

- 名称：白鹿（Bailu）
- 前缀：bailu:
- 命令：`/bailu-sdd-start`
- 寓意：林深见鹿——在复杂的代码森林中，发现优雅的解决方案

## 功能

白鹿 SDD 研发流程入口，启动或继续 SDD 七阶段研发管理流程：

1. **D1 任务分配与评估** — 任务拆解、SP 估算、规模推荐
2. **D2 技术方案设计** — 代码锚定、OpenSpec 文档生成
3. **D3 技术方案评审** — AI 自检 / 正式评审会
4. **D4 开发编码** — 逐任务实现，白鹿 Agent 协作
5. **D5 代码评审** — AI 审核 + 人工审核双重闸门
6. **D6 测试与缺陷闭环** — 四环节测试，缺陷必须闭环
7. **D7 上线/发版** — 上线前检查 + MR 创建（可选）

支持三级规模路由：
- 小需求（快速模式）：D1 → D4 → D5 → D6
- 中等需求（标准模式）：D1-D6，D3 AI 自检
- 大需求（完整模式）：D1-D7，D3 正式评审会

## 执行流程

1. 环境预检（Git、OpenSpec CLI 可用性）
2. 读取 `.sdd/sdd-context.md` 判断当前阶段
3. 展示进度和意图确认
4. 路由到对应 D1-D7 阶段 Skill 执行

## 使用方式

```bash
# SDD 流程入口（推荐）
/bailu-sdd-start

# 带需求信息启动
/bailu-sdd-start PROJ-12345 订单列表 Excel 导出

# 白鹿原有入口（SDD 可用时自动路由）
/bailu-dev
```
