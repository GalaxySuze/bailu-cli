# 代码质量标准

## 通用标准

### 可读性
- 变量、函数、类命名清晰，见名知意
- 函数保持单一职责，不超过 50 行
- 复杂逻辑添加中文注释说明意图
- 避免魔法数字，使用命名常量

### 健壮性
- 所有外部输入进行校验
- 异步操作需处理错误
- 资源（文件、连接）使用后正确释放
- 关键操作添加日志记录

### 性能
- 避免在循环中进行不必要的计算
- 大数据量操作使用分页或流式处理
- 合理使用缓存减少重复计算
- 注意 N+1 查询问题

## 语言特定规范

### JavaScript/TypeScript
- 使用 const/let，禁用 var
- 优先使用箭头函数
- 使用解构赋值简化代码
- 使用可选链 (?.) 和空值合并 (??)
- TypeScript 项目避免使用 any

### Python
- 遵循 PEP 8 编码规范
- 使用类型注解
- 使用 f-string 格式化字符串
- 使用 with 语句管理资源

### Go
- 遵循 Go 官方代码规范
- 错误处理不忽略
- 使用 defer 管理资源
- 导出函数需有文档注释

## 禁止事项

- 不提交调试代码（console.log、print 等）
- 不提交敏感信息（密钥、密码、Token）
- 不引入未经评审的第三方依赖
- 不在生产代码中使用 eval() 或类似函数
- 不忽略编译器/类型检查警告
