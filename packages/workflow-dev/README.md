# @bailu/workflow-dev

白鹿开发工作流 - 适用于团队开发

## 安装

```bash
npm install -g @bailu/workflow-dev
```

## 使用

```bash
# 安装工作流到配置中心
bailu workflow install dev

# 安装到AI工具
bailu tool install
```

## 包含内容

### Skills

- `bailu-dev-workflow` - 开发工作流
- `bailu-init` - 初始化工作流

### Commands

- `/bailu-dev` - 进入开发工作流
- `/bailu-init` - 初始化工作流

## 触发词

- 开发、代码、bug、重构、API、数据库、部署、测试
- 初始化工作流、init workflow
