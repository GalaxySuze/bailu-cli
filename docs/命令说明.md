# 白鹿工作流命令说明

## 命令总览

| 命令 | 执行环境 | 作用 |
|------|---------|------|
| `/bailu-dev-workflow` | Claude (Skill) | 开发工作流技能定义，描述四阶段流程 |
| `/bailu-dev` | Claude (Command) | 激活开发工作流，进入四阶段开发模式 |
| `/bailu-init` | Claude (Command) | 项目级初始化，生成 CLAUDE.md 和工作流配置 |
| `bailu init` | 命令行 (CLI) | 全局配置中心初始化，创建 ~/.bailu/ 目录 |

---

## 详细说明

### 1. `/bailu-dev-workflow` (Skill)

**类型**：技能（Skill）  
**作用**：定义开发工作流的完整流程，包含四个阶段：

```
需求讨论 → 方案文档 → AI Coding → 交付
```

**特点**：
- 是一个"知识定义"，告诉 Claude 如何执行开发工作流
- 不直接执行，而是被 `/bailu-dev` 命令激活
- 包含每个阶段的推荐工具和人工介入节点

---

### 2. `/bailu-dev` (Command)

**类型**：命令（Command）  
**作用**：激活 `bailu-dev-workflow` 技能，进入开发工作流

**使用场景**：
```
用户：/bailu-dev
Claude：进入白鹿开发工作流，请描述你的需求...
```

**与 Skill 的关系**：
- `/bailu-dev` 是快捷入口
- `/bailu-dev-workflow` 是被激活的技能内容
- 两者配合使用，Command 负责触发，Skill 负责执行

---

### 3. `/bailu-init` (Claude Command)

**类型**：Claude 命令  
**作用**：在 Claude 中执行项目级初始化

**执行流程**：
1. 扫描当前项目目录
2. 分析技术栈（package.json、composer.json 等）
3. 生成或更新 CLAUDE.md
4. 叠加白鹿工作流配置引用
5. 创建 `.claude/rules/` 目录结构

**使用场景**：
```
用户：/bailu-init
Claude：检测到 Node.js 项目，正在初始化工作流配置...
```

---

### 4. `bailu init` (CLI Command)

**类型**：CLI 命令  
**作用**：初始化白鹿全局配置中心

**执行内容**：
1. 创建 `~/.bailu/` 目录结构
2. 初始化注册表 `registry.json`
3. 创建工作流记录 `installed.json`
4. 创建配置目录（skills、commands、agents、hooks 等）

**使用场景**：
```bash
$ bailu init

🦌 Bailu Init

   ✓ 目录结构创建完成
   ✓ 注册表创建完成
   ✓ 工作流记录创建完成

✅ 初始化成功
```

---

## 核心区别

### `/bailu-init` vs `bailu init`

| 维度 | `/bailu-init` | `bailu init` |
|------|---------------|--------------|
| 执行环境 | Claude 内部 | 命令行终端 |
| 作用范围 | 当前项目 | 全局配置 |
| 主要产物 | CLAUDE.md + 工作流配置 | ~/.bailu/ 目录结构 |
| 使用时机 | 新项目需要接入工作流时 | 首次安装 CLI 后 |

### `/bailu-dev` vs `/bailu-dev-workflow`

| 维度 | `/bailu-dev` | `/bailu-dev-workflow` |
|------|--------------|----------------------|
| 类型 | Command（命令） | Skill（技能） |
| 作用 | 触发入口 | 执行内容 |
| 关系 | 负责激活 | 被激活后执行 |

---

## 典型使用流程

### 场景：新项目接入白鹿工作流

```bash
# 1. 全局初始化（首次安装后执行一次）
bailu init

# 2. 安装开发工作流
bailu install dev

# 3. 在 Claude 中初始化项目配置
/bailu-init

# 4. 开始开发
/bailu-dev
```

### 场景：已有项目开始新功能开发

```bash
# 直接在 Claude 中进入开发工作流
/bailu-dev
```

### Skill 定义位置
```
~/.bailu/config/skills/
├── bailu-dev-workflow/SKILL.md
└── bailu-init/SKILL.md
```

### Command 定义位置
```
~/.bailu/config/commands/
├── bailu-dev.md
└── bailu-init.md
```

### CLI 命令实现
```
packages/cli/src/commands/init.js
```
