# TUI 仪表盘

白鹿工作流提供了一个精美的终端仪表盘，无需任何参数即可查看系统状态。

## 启动方式

```bash
bailu
```

直接运行 `bailu` 命令（不带任何参数），即可显示 TUI 仪表盘。

## 仪表盘内容

```
╭─────────────────────────────────────────────────────╮
│  🦌 白鹿工作流 · AI Coding 环境管理工具            │
├─────────────────────────────────────────────────────┤
│  系统: macOS (darwin)                               │
│  Node: v23.5.0                                      │
│  CLI: 1.1.0                                         │
├─────────────────────────────────────────────────────┤
│  工作流: 2 已安装                                    │
│  组件:   15 Skills, 8 Commands, 3 Agents            │
│  工具:   6 已配置                                    │
╰─────────────────────────────────────────────────────╯
```

## 信息说明

| 信息项 | 说明 |
|--------|------|
| 系统 | 当前操作系统类型 |
| Node | Node.js 版本号 |
| CLI | 白鹿工作流版本号 |
| 工作流 | 已安装的工作流数量 |
| 组件 | 各类型组件数量统计 |
| 工具 | 已配置的 AI 工具数量 |

## 快捷命令

在 TUI 仪表盘中，可以直接看到常用命令提示：

```
╭─────────────────────────────────────────────────────╮
│  常用命令                                           │
├─────────────────────────────────────────────────────┤
│  bailu init              初始化配置                 │
│  bailu install dev       安装开发工作流             │
│  bailu status            查看详细状态               │
│  bailu serve             启动 WebUI                 │
╰─────────────────────────────────────────────────────╯
```
