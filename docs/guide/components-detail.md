# 工作流组件详解

本文档详细列出白鹿工作流 base 和 dev 工作流中包含的所有组件，包括 Skills、Commands、Agents、Hooks、Rules 和 MCP。

## 组件概览

| 类型 | 数量 | 说明 |
|------|------|------|
| Skills | 20+ | AI 技能，定义 AI 的能力 |
| Commands | 15+ | 命令，扩展 CLI 功能 |
| Agents | 10+ | 代理，定义 AI 角色 |
| Hooks | 4 | 钩子，自动化操作 |
| Rules | 3 | 规则，约束 AI 行为 |
| MCP | 2+ | 模型上下文协议服务 |

## Rules 规则

### common

> 通用规则

**作用**：通用编码规范和最佳实践。

**包含内容**：
- 命名规范
- 代码风格
- 注释规范
- 错误处理

**适用范围**：所有项目

**示例规则**：
```markdown
# 命名规范
- 使用有意义的变量名
- 遵循项目命名约定
- 避免缩写

# 代码风格
- 使用一致的缩进
- 控制行长度
- 合理使用空行
```

---

### python

> Python 规则

**作用**：Python 项目专用规则。

**包含内容**：
- PEP 8 规范
- 类型注解
- 虚拟环境
- 依赖管理

**适用范围**：Python 项目

**示例规则**：
```markdown
# PEP 8
- 使用 4 空格缩进
- 行长度不超过 79 字符
- 使用蛇形命名法

# 类型注解
- 函数参数添加类型注解
- 返回值添加类型注解
```

---

### typescript

> TypeScript 规则

**作用**：TypeScript 项目专用规则。

**包含内容**：
- 类型定义
- 接口规范
- 泛型使用
- 严格模式

**适用范围**：TypeScript 项目

**示例规则**：
```markdown
# 类型定义
- 使用 interface 定义对象类型
- 使用 type 定义联合类型
- 避免使用 any

# 严格模式
- 启用 strict 模式
- 处理所有类型错误
```
