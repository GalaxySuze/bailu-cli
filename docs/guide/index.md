# 项目简介

## 什么是白鹿工作流？

**白鹿工作流 CLI**（`bailu`）是一款面向 **AI 辅助开发**的工作流管理工具，专为在多种 AI 编程工具之间统一管理配置文件和工作流组件而设计。

> **林深见鹿**——在复杂的规则森林中，发现优雅的解决方案

## 核心价值

白鹿工作流解决了以下核心痛点：

### 配置碎片化

AI 工具配置分散在各个目录，难以统一管理。白鹿工作流通过统一的配置中心（`~/.bailu/`）集中管理所有配置。

### 团队不一致

团队成员使用的 AI 工具配置各不相同，协作效率低下。白鹿工作流通过 `sync` 命令保持团队配置同步。

### 工作流复用难

优质的 Skills/Commands/Agents/Rules 无法快速分享和复用。白鹿工作流将这些组件打包为可安装的工作流包。

### 工具迷茫感

AI 编程工具种类繁多，难以快速找到适合自己的工具。白鹿工作流内置 AI 工具推荐系统。

## 适用场景

| 场景 | 描述 |
|------|------|
| **团队协作** | 统一团队 AI 工具配置，通过 sync 命令保持所有成员配置同步 |
| **个人开发** | 快速安装精心设计的工作流（dev/ops），提升 AI 辅助开发效率 |
| **工具评估** | 通过 recommend 命令浏览和发现优质 AI 编程工具 |
| **MCP 管理** | 统一管理 MCP（Model Context Protocol）服务配置 |
| **代码质量** | 通过 Git Hooks 和 audit 命令保障代码质量与安全 |

## 核心特性

- **TUI 仪表盘**：无参数运行 `bailu` 即可查看精美的终端仪表盘
- **一键安装工作流**：将精心设计的 dev/ops 工作流安装到目标 AI 工具
- **多工具支持**：支持 Claude Code、Codex、Cursor、Windsurf 等主流 AI 工具
- **WebUI 管理平台**：图形界面管理工作流、MCP 配置、推荐工具
- **团队同步机制**：基于 Git 的配置同步，保持团队统一
- **AI 工具推荐**：内置精选 AI 工具数据库，支持社区自定义推荐
- **MCP 服务管理**：便捷添加、删除、启用/禁用 MCP Server
- **安全审计**：对已安装的组件进行安全审计

## 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                    白鹿工作流 CLI                            │
├─────────────────────────────────────────────────────────────┤
│  CLI 层 (Commander.js)                                      │
│  ├── bailu init          # 初始化配置                       │
│  ├── bailu workflow       # 工作流管理                       │
│  ├── bailu tool           # AI 工具管理                     │
│  ├── bailu mcp            # MCP 服务管理                    │
│  ├── bailu sync           # 团队同步                        │
│  └── bailu serve          # 启动 WebUI                      │
├─────────────────────────────────────────────────────────────┤
│  配置层 (~/.bailu/)                                         │
│  ├── config/              # 工作流配置                       │
│  ├── plugins/             # 插件配置                         │
│  └── projects.json        # 项目配置                         │
├─────────────────────────────────────────────────────────────┤
│  工具层                                                     │
│  ├── Claude Code          # ~/.claude/                      │
│  ├── Hanako               # ~/.hanako/                      │
│  ├── Codex                # ~/.codex/                       │
│  ├── Cursor               # ~/.cursor/                      │
│  └── 其他 AI 工具...                                        │
└─────────────────────────────────────────────────────────────┘
```
