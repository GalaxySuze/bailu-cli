# 安全审计

白鹿工作流提供了安全审计功能，可以检查已安装组件的安全性。

## 运行审计

### 命令行方式

```bash
# 运行审计
bailu audit

# 自动修复问题
bailu audit --fix

# JSON 格式输出
bailu audit --json
```

### WebUI 方式

```bash
# 启动 WebUI
bailu serve

# 访问 http://localhost:3000 → 安全审计
```

## 审计内容

### Skills 审计

检查 Skills 文件的安全性：
- 文件权限检查
- 敏感信息检查
- 恶意代码检查

### Commands 审计

检查 Commands 文件的安全性：
- 命令注入检查
- 权限提升检查
- 路径遍历检查

### Agents 审计

检查 Agents 配置的安全性：
- 角色权限检查
- 访问控制检查
- 数据泄露检查

### Rules 审计

检查 Rules 配置的安全性：
- 规则冲突检查
- 权限过宽检查
- 安全漏洞检查

### Hooks 审计

检查 Hooks 文件的安全性：
- 脚本安全检查
- 执行权限检查
- 注入风险检查

## 审计结果

### 信任分数

审计结果以信任分数形式展示：

| 分数 | 等级 | 说明 |
|------|------|------|
| 80-100 | 安全 | 未发现安全问题 |
| 60-79 | 低风险 | 存在轻微风险 |
| 0-59 | 需要审查 | 存在严重问题 |

### 问题等级

| 等级 | 说明 |
|------|------|
| HIGH | 高风险问题，需要立即修复 |
| MEDIUM | 中风险问题，建议修复 |
| LOW | 低风险问题，可选修复 |

## 自动修复

对于某些问题，审计工具可以自动修复：

```bash
# 自动修复所有可修复的问题
bailu audit --fix
```

可修复的问题包括：
- 文件权限问题
- 配置格式问题
- 缺失的必填字段

## 最佳实践

### 1. 定期审计

建议定期运行安全审计：

```bash
# 每周运行一次
bailu audit
```

### 2. 集成到 CI/CD

可以将审计集成到 CI/CD 流程：

```yaml
# GitHub Actions
- name: Security Audit
  run: bailu audit --json
```

### 3. 及时修复

发现问题后及时修复：

```bash
# 查看问题详情
bailu audit

# 自动修复
bailu audit --fix

# 手动修复后重新审计
bailu audit
```
