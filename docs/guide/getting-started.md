# 快速开始

本指南将帮助你在 5 分钟内上手白鹿工作流。

## 前置条件

| 依赖 | 最低版本 | 说明 |
|------|----------|------|
| Node.js | **18.0.0** 及以上 | 运行时环境 |
| npm | 随 Node.js 附带 | 包管理器 |
| Git | 任意版本 | 团队同步功能需要 |

验证 Node.js 版本：

```bash
node --version
# 应输出 v18.x.x 或更高版本
```

## 第一步：安装

```bash
npm install -g @vickzhang/bailu-cli
```

安装完成后，验证安装：

```bash
bailu -v
# 输出：1.1.0
```

## 第二步：初始化配置

```bash
bailu init
```

初始化命令会：
1. 创建 `~/.bailu/` 配置目录
2. 创建默认工作流配置
3. 检测已安装的 AI 工具

## 第三步：安装工作流

安装开发工作流（SDD 增强版）：

```bash
bailu workflow install dev
```

这会将开发工作流的组件安装到你的 AI 工具目录中，包括 SDD 七阶段研发管理 Skills。

安装完成后，在 AI 工具中使用：

```bash
# SDD 研发流程入口（推荐）
/bailu-sdd-start

# 带需求信息启动
/bailu-sdd-start QYHT-29001 订单列表 Excel 导出

# 白鹿原有入口（自动路由到 SDD）
/bailu-dev
```

## 第四步：查看状态

```bash
bailu status
```

输出示例：

## 第五步：启动 WebUI

```bash
bailu serve
```

浏览器会自动打开 `http://localhost:3000`，你可以在 WebUI 中：

- 查看工作流详情
- 管理 AI 工具配置
- 管理项目和 Rules
- 运行安全审计
