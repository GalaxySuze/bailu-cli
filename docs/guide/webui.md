# WebUI 管理

白鹿工作流提供了一个现代化的 Web 管理界面，可以直观地管理工作流、组件和配置。

## 启动 WebUI

```bash
bailu serve
```

浏览器会自动打开 `http://localhost:3000`。

## 页面说明

### 工作区

工作区是 WebUI 的首页，展示：
- AI 工具状态卡片
- 当前项目信息
- 系统信息
- 工作流快速安装

### 工作流

管理工作流的安装和配置：
- 查看已安装的工作流
- 安装新的工作流
- 查看工作流详情

### 组件

查看和管理各类组件：
- Skills（技能）
- Commands（命令）
- Agents（代理）
- Hooks（钩子）
- Rules（规则）
- MCP（模型上下文协议）

### AI 工具

管理 AI 编程工具配置：
- 查看已配置的工具
- 安装工具配置
- 查看组件统计

### 项目管理

管理项目路径和 Rules 配置：
- 添加/删除项目
- 设置当前项目
- 管理项目 Rules

### 安全审计

对已安装的组件进行安全审计：
- 检查安全漏洞
- 查看信任分数
- 查看审计详情

## 自定义端口

```bash
bailu serve --port 8080
```

## 局域网访问

```bash
bailu serve --host 0.0.0.0
```
