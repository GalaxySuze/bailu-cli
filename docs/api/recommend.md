# bailu recommend

AI 工具推荐。

## 用法

```bash
bailu recommend [options]
```

## 选项

| 选项 | 说明 |
|------|------|
| `-c, --category <category>` | 按分类筛选 |
| `-t, --tool <tool>` | 查看特定工具详情 |

## 示例

```bash
# 查看推荐列表
bailu recommend

# 按分类筛选
bailu recommend --category code

# 查看工具详情
bailu recommend --tool claude
```

## 工具分类

| 分类 | 说明 |
|------|------|
| `code` | 代码生成工具 |
| `chat` | 对话工具 |
| `design` | 设计工具 |
